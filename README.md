# Gondar-B2B-Logistics
B2B beverage ordering, Isuzu truck delivery routing, and spent-grain allocation platform for Gondar.
# Team COBRAW: Gondar B2B Beverage Logistics & Spent-Grain Platform

## 1. Problem Identification
In Gondar, beverage distribution (beer, bottled water, soft drinks) relies on Isuzu trucks roaming streets to visually spot empty crates at venues. This causes high fuel waste, stockouts, and payment reconciliation issues. Additionally, livestock farmers face gatekeeping when trying to buy brewery spent grain.

## 2. Solution Architecture
- **Bar Pre-Orders:** Venues schedule deliveries and declare 24-bottle beer crate returns in advance.
- **Scheduled Dispatch:** Drivers follow fixed routes based on paid orders (processed via Links.et).
- **Spent-Grain Booking:** Farmers reserve spent-grain quotas and receive digital entry passes.
- **Voice Integration (Voxide):** Drivers log crate deliveries via voice; farmers check inventory by voice.

## 3. Academic & Literature Basis (ScholarXIV Integration)
This project uses the ScholarXIV Papers API to reference supply chain logistics models in emerging markets.
